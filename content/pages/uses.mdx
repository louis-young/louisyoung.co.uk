## This site

In October 2026 I rebuilt this site from a 2021 Gatsby blog into a static Astro site. The [colophon](/colophon/) covers the design and accessibility; this is the toolbox, and why each piece is there.

- **[Astro](https://astro.build) 7** renders every page to static HTML. I picked it over Next.js because the site needs no server and almost no client-side JavaScript.
- **React 19** only runs the live demos in articles, hydrated as islands when they scroll into view.
- **TypeScript** in strict mode throughout. Articles, snippets and pages are content collections with Zod schemas, so a bad frontmatter field fails the build rather than the live site.
- **MDX** for articles, snippets and pages like this one.
- **Tailwind CSS 4** for the reset and utilities. Most styling is component-scoped CSS on a small set of OKLCH design tokens.
- **Geist and Geist Mono**, self-hosted, so there's no third-party font request.
- **Expressive Code** highlights code at build time and adds the copy button, so no highlighter ships to the browser.
- **Pagefind** indexes the built site, so search runs entirely in the browser with nothing behind it.
- **Satori and resvg** draw the Open Graph images and icons from the site's own fonts at build time, and **pdf-lib** generates the CV PDF from the same data as the web version.
- **[Vercel](https://vercel.com)** hosts it, with a preview deployment for every pull request. Its Web Analytics is cookieless, which is why there's no consent banner.
- **Vitest** runs the unit, integration, type and content tests. **Playwright** runs end-to-end, accessibility (with axe) and visual regression tests. Visual baselines are only rendered in a pinned container, so they don't drift between machines.
- **Prettier, ESLint, cspell, ls-lint and knip** check formatting, code, spelling, file names and unused code. Lefthook runs them before a commit, and commitlint keeps commit messages conventional.
- **Lighthouse CI** runs on every pull request with performance budgets.

The [source is on GitHub](https://github.com/louis-young/louisyoung.co.uk).

## Writing about

My articles are about React and the JavaScript underneath it: state and hooks (functional state updates, avoiding derived state), the Context API, protected routes with React Router, fetching data with the Fetch API, destructuring props, and implicit and explicit returns. Most of them have a live demo or an embedded sandbox.

The [snippets](/snippets/) lean towards TypeScript (`satisfies`, exhaustive switches with `never`, typed debounce and throttle), small React hooks, and CSS that holds up for everyone: focus rings in forced colours, a fluid type scale with `clamp()` and a visually hidden utility.
