## Building

Mostly this site. In October I rebuilt it from a 2021 Gatsby blog into a static Astro site with a proper test suite, and then kept going:

- **[Tools](/tools/):** 25 small developer tools that run entirely in the browser, from a JSON to TypeScript converter and a regex tester to cron, semver and chmod helpers.
- **[Snippets](/snippets/):** short, copy-pasteable code, mostly TypeScript, React hooks and accessible CSS. Every TypeScript block is type-checked when the site builds.
- **A [map](/map/)** of how the site's topics connect, and a [changelog](/changelog/) built from the git history.
- **Accessibility:** an audit, the fixes that came out of it and an [accessibility statement](/accessibility/).

## Writing
