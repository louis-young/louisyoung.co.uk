When a union grows a new member, every `switch` over it should fail to compile until it handles the new case. TypeScript can do that for you: in the `default` branch, the value has been narrowed to `never`, so passing it to a function that only accepts `never` is a type error the moment a case is missing.

```ts title="assert-never.ts"
export function assertNever(value: never, message = "Unhandled value"): never {
  throw new Error(`${message}: ${JSON.stringify(value)}`);
}
```

```ts title="area.ts"
import { assertNever } from "./assert-never";

type Shape =
  | { kind: "circle"; radius: number }
  | { kind: "square"; size: number }
  | { kind: "rectangle"; width: number; height: number };

export function area(shape: Shape): number {
  switch (shape.kind) {
    case "circle":
      return Math.PI * shape.radius ** 2;
    case "square":
      return shape.size ** 2;
    case "rectangle":
      return shape.width * shape.height;
    default:
      return assertNever(shape, "Unknown shape");
  }
}
```

Add `{ kind: "triangle"; base: number; height: number }` to `Shape` and the `default` branch stops compiling with "Argument of type `{ kind: "triangle"; … }` is not assignable to parameter of type `never`", pointing straight at the switch you forgot.

## Why it works

Each `case` narrows `shape.kind`, and by the `default` branch every member of the union has been ruled out, leaving `never`. Only `never` is assignable to `never`, so any member you haven't handled shows up as a type error with its exact shape in the message.

Returning `assertNever(…)` also keeps the function's return type honest: because it returns `never`, TypeScript knows the `default` branch can't fall out of the function without a value.

## Gotchas

- The type check only protects typed code. Data from an API, `localStorage` or an old cache can still contain a `kind` you've never heard of, which is why the helper throws instead of doing nothing. Log it and fail loudly.
- `JSON.stringify` throws on a `bigint` and drops functions, so keep the message simple if your unions carry those.
- If you'd rather not throw, `shape satisfies never;` in the `default` branch gives you the compile-time check with no runtime cost.
- typescript-eslint's `switch-exhaustiveness-check` rule catches the same mistake in switches that don't have a `default` at all.
