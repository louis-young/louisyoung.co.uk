# Security policy

This repository builds a static website. If you find a vulnerability in the site, its headers or Content Security Policy, its build pipeline or its GitHub workflows, please report it privately.

## Reporting

- Preferred: [open a private security advisory](https://github.com/louis-young/louisyoung.co.uk/security/advisories/new).
- Or email me@louisyoung.co.uk.

Please include steps to reproduce and the impact. You can expect an acknowledgement within a few days. Please don't open a public issue for security problems.

The same contact details are published at [/.well-known/security.txt](https://louisyoung.co.uk/.well-known/security.txt).

## Scope

In scope: louisyoung.co.uk and this repository's code and workflows. Out of scope: third-party services the site links to or embeds on request (for example CodeSandbox).
