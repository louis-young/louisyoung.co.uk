# Bug hunt: tools, share links and the palette

A pass over the code merged in the last day (`src/lib`, `src/scripts`, `src/pages/tools`), looking for correctness bugs. Each confirmed bug has a unit test that failed before the fix.

## Checked and fine

- **Arithmetic parser**: precedence, unary minus (`-2^2` is -4), right-associative `^` (`2^3^2` is 512), division and remainder by zero, `10^400` and `9^9^9` (not finite, so no answer), 200-character nesting. Nothing loops: the input is capped and every rule consumes a token.
- **Share links**: malformed base64url, a length of 1 mod 4, invalid UTF-8, `__proto__` keys, arrays, nested values and oversized fragments all decode to nothing. Every share-enabled tool restores its controls before or after its own start-up in a way that wins over defaults (the diff tool's narrow-screen default runs before the restore).
- **Cron**: next runs across month ends, 29 February, and both UK daylight-saving changes in local time (a skipped 01:30 doesn't fire; a repeated one fires once).
- **Base converter**: negative numbers, two's complement at every width, 64-bit unsigned values, prefixes in other bases (`0b1` in hex is a hex number).
- **QR**: byte capacity matches ISO 18004 for versions 1 and 40, and is measured in UTF-8 bytes.
- **Semver pre-release ordering**: numeric before alphanumeric, shorter before longer, `<2.0.0-0` keeps pre-releases out.
- **Map layout**: the same content in a different order gives the same layout.
- **Recent tools**: storage that throws on read or write, and malformed stored values.

## Worth a look

Behaviour that looks deliberate, so it is left alone.

| Area                  | Input                                               | What happens                                                                                     |
| --------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Palette quick answers | `2023-2024`, `24/7`, `9-5`                          | Read as sums (-1, 3.43, 4). Year ranges and idioms are common searches.                          |
| Palette quick answers | `1 2 3 4 5`, `123456789`                            | Five small numbers are a cron schedule; a nine-digit number is a 1973 timestamp.                 |
| Timestamp             | `1700000000000000` (microseconds)                   | Read as milliseconds: the year 55840, with no hint that it may be microseconds.                  |
| Timestamp             | `2026-10-09T10:00`                                  | Read as UTC (flagged in the tool), where JavaScript's `Date` reads it as local time.             |
| Cron                  | `30 1 * * *` in local time across the spring change | The skipped run never fires; the classic cron daemon runs it straight after the jump.            |
| Semver                | `1.0.0-20231009123456789` vs `…790`                 | Numeric identifiers above 2^53 lose precision and compare as equal (npm treats them as strings). |
| URL builder           | `?flag`                                             | Editing any parameter rewrites it as `?flag=`, and spaces as `+`; equivalent for most servers.   |
| URL builder           | a path ending in `%20`                              | "Decode" shows a trailing space, which trimming then drops.                                      |
| Markdown table        | a cell ending in `\` with "compact"                 | `\|` escapes the cell's closing pipe in GFM, merging it with the next cell.                      |
| chmod                 | a path starting with `-`                            | `chmod 755 -rf` reads the path as options; `--` or `./` would keep it a path.                    |
